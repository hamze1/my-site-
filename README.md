# سایت kyanai.ir

## ساختار
```
kyanai-site/
├── index.html   ← همه‌چیز (متن، استایل، اسکریپت) در همین یک فایل است
└── images/      ← عکس‌ها (فعلاً خالی)
```

فقط عکس‌ها جدا نگه داشته شده‌اند تا مرورگر موبایل بدون مشکل مسیر نسبی، فایل را کامل نمایش بدهد.
اگر بعداً پروژه را روی هاست/سرور واقعی گذاشتید، می‌توانید دوباره CSS و JS را به فایل‌های جدا تقسیم کنید.

## چطور اجرا کنم؟
فقط `index.html` را با مرورگر باز کنید — به هیچ فایل یا پوشه‌ی دیگری وابسته نیست.

## چطور شخصی‌سازی کنم؟
- **متن‌ها**: داخل `index.html`، بین تگ‌های `<body>`.
- **رنگ‌ها و فونت‌ها**: داخل `index.html`، در تگ `<style>`، بخش `:root` بالای فایل.
- **عکس‌ها**: فایل عکس را در پوشه `images/` بگذارید و در `index.html` با مسیر `images/نام-فایل.jpg` صدا بزنید.
- **دکمه «ارسال پیام در اینستاگرام»**: دنبال `class="btn btn-primary btn-lg"` بگردید و لینک واقعی خود را در `href` جایگزین کنید.

## ارسال لید از فرم چت هوشمند به بله

سایت روی GitHub Pages هاست شده — یعنی فقط فایل‌های ساده (HTML/CSS/JS) اجرا می‌شوند و کد سمت سرور
(PHP، Node و غیره) کار نمی‌کند. به همین دلیل فرم چت هوشمند (کیان) این‌طور کار می‌کند:

1. کاربر اسم، فامیل، شماره و پیام را وارد می‌کند
2. متن پیام خودکار در کلیپ‌بورد گوشی/کامپیوترش کپی می‌شود
3. بله باز می‌شود (چت مستقیم با شما)
4. کاربر فقط پیست (چسباندن) می‌کند و ارسال می‌زند

این روش کاملاً سمت مرورگر است، هیچ سروری لازم ندارد و روی هر هاستی (از جمله GitHub Pages) کار می‌کند.

### اگر بعداً هاست PHP/Node گرفتی
اگر یک روز یک هاست با پشتیبانی PHP یا Node گرفتی، می‌شود این مرحله را کاملاً خودکار کرد
(بدون نیاز کاربر به کپی/پیست کردن) — با یک ربات بله که خودش مستقیم برایت پیام می‌فرستد.
اگر به این مرحله رسیدی، بگو تا آن نسخه را دوباره برایت آماده کنم.
